## ⚠️ 발표자료와 이 저장소의 수치 차이

| 항목 | 발표자료 | 이 저장소 | 왜 |
|---|---|---|---|
| Macro-F1 (thr) | 0.6395 (thr=0.03) | 동일 | 성능 최고점 |
| Macro-F1 (기본) | 0.618 / 0.6138 | **0.6138** | 슬라이드에 반올림 표기가 섞여 있음 |
| "정식 확정 Macro-F1" | 0.6395 (thr=0.03) | 동일 | 최종 발표 p.37 '완료' 항목 |
| 운영 임계값 | 0.005 | 동일 | |

발표자료 p.37 에 `Macro-F1 0.6395 (thr=0.03)` 이 '완료' 항목으로 적혀 있는데,
**운영에 실제로 넣은 값은 `0.005`(Macro-F1 0.603)** 입니다.
성능 최고점과 운영 채택값이 다른 이유는 [`docs/07` §2](../docs/07_model_and_thresholds.md) 를 보세요.
