## 🤖 5. AI 챗봇 (신규 · `chat_agent.py`)

사이드바 하단 **`🤖 AI 챗`** 토글로 진입. 켜면 대화 히스토리 + 입력창이 도킹되고, 끄면 화면을 차지하지 않음.

### 5-a. 읽기 전용 해설 (증분 1)
- 현재 화면 상태(세션·임계값·최근 판정·배치 요약)를 읽어 쉬운 말로 해설.
- 세션5 LLM 설정(`_build_llm_analyzer`)을 그대로 재사용. 멀티턴은 대화+상태를 단일 프롬프트로 평탄화해 `_call`에 전달(모든 프로바이더 호환).
- **PII 락**: `_build_masker()` 정책 승계 — 로컬+스킵이면 원문 유지·외부 전송 차단, 외부 프로바이더면 마스킹. 상태 배지로 현재 보호 상태 표시.

### 5-b. 프롬프트 라이브 편집 (증분 2)
- 챗 패널의 **`⚙️ 프롬프트 편집`**에서 시스템 지시문을 즉시 수정(세션 저장, 재시작 불필요). 되돌리기 지원.
- 영구 기본값은 `chat_agent.py`의 `_SYSTEM`(언어별) 편집.
- 동작 안내(`actions_prompt`)는 자동 부착되어, 프롬프트를 어떻게 편집해도 에이전트 기능은 유지.

### 5-c. 에이전트 동작 — 7개 액션 (증분 3·4)
텍스트 프로토콜 `[[ACTION: name(arg)]]` (로컬 모델 포함 전 프로바이더 호환). **화이트리스트 + 인자 검증 + pending 패턴**으로 안전.

| 액션 | 설명 |
|---|---|
| `goto_session(1~5)` | 메인 세션 이동 |
| `goto_s5_tab(manual/test/train/synthetic/folder)` | 세션5 입력 방식 탭 |
| `set_manual_field(field, value)` | 직접입력 값(amount·distance·balance·channel·os) |
| `run_detection()` | 직접입력 값으로 탐지 실행 |
| `goto_batch_subtab(all/analysis/slack/email)` | 배치 결과 하위 탭 |
| `set_manual_flag(name, on/off)` | 위험 플래그 토글(부분매칭: rooting·vpn·unused…) |
| `set_beginner_mode(on/off)` | 초보자 설명 토글 |

**안전장치 2단**
- 파서(`chat_agent`): 화이트리스트 이름 + 구조/범위/enum 검증.
- 실행기(`dashboard`): 도메인 값 검증(예: `channel=HACK`는 `CAT_OPTIONS`에 없어 드롭, 숫자는 범위 clamp). 위젯 key는 **pending 예약** 후 세션5 렌더 직전 적용 → Streamlit 예외 원천 차단.

**확장 방법**: 액션 추가 = `chat_agent.py`의 `ACTIONS`에 항목 + `dashboard`의 `_apply_chat_actions`에 분기 한 줄.

## ⚠️ 알려진 제약 · 다음 후보

- **로컬 약한 모델(예: Gemma)** 은 `[[ACTION]]` 문법을 안정적으로 뱉지 못할 수 있음 → 이 경우 일반 답변만 하고 동작은 생략(무해). 클라우드 모델이 가장 안정적.
- **응답 스트리밍(미구현)**: 진짜 토큰 스트리밍은 `llm_analyzer`에 프로바이더별 `stream=True` 경로를 새로 뚫어야 하고, 스트리밍 중엔 액션 파싱을 분리해야 하는 **중간 규모 작업**. 다음 릴리스 후보.
- 에이전트 값 입력/트리거는 현재 **직접입력(manual) 탭** 중심. 다른 입력 모드(test/train/synthetic/folder)의 실행 트리거는 확장 여지.
